# DB + Attractor Frontend (React + Vite)

## Run locally

```bash
cd frontend
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env` and set backend API URL.

## Included features

- Login / Register pages with JWT persistence
- Protected routes with React Router
- Dashboard metrics + lead status chart + recent activity
- Clients CRUD table with search, filter, and pagination
- Leads pipeline with stage transitions and assignee updates
- Tailwind responsive app shell + sidebar navigation
